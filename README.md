# OPEN MOUTH 1.0

재성 / 송희 두 사람이 매일 10분씩 실제로 영어를 말하게 만드는 개인용 AI 영어회화 앱입니다.

## 1.0 완성 흐름

1. 재성 / 송희 프로필 선택
2. 최초 1회 30초 음성 레벨테스트
3. 전날 복습 문장 30초
4. 최근 학습 이력을 보고 오늘의 미션 자동 추천
5. AI와 실시간 음성 역할극
6. 세션 종료 후 핵심 교정 3개
7. 내일 복습 문장 자동 저장
8. 다시 말하기 정확도 80점 이상 통과
9. 주간 리포트 확인

## 포함 기능

- OpenAI Realtime 음성 대화
- 사용자 음성 자동 전사
- 재성 / 송희 학습 데이터 완전 분리
- SQLite 영구 저장
- 30개 실전 회화 미션
- 여행 / 음식 / 쇼핑 / 일상 / 업무 / 문제 해결 카테고리
- 최근 학습 이력 기반 미션 자동 추천
- 5단계 난이도
- 30초 음성 레벨테스트
- 세션 종료 후 AI 교정 3개
- 자동 복습 큐
- 복습 문장 직접 녹음
- 말하기 정확도 점수 및 80점 통과
- 연속 학습일 / 이번 주 / 누적 학습시간
- 주간 리포트
- PWA manifest + service worker
- 모바일 반응형 UI

## 실행

Node.js 20+ 필요

```bash
npm install
```

`.env.example`을 `.env`로 복사한 뒤:

```env
OPENAI_API_KEY=sk-...
PORT=3000
```

실행:

```bash
npm run dev
```

브라우저:

```text
http://localhost:3000
```

## 주의

- OpenAI API 사용량에 따라 비용이 발생합니다.
- API 키는 브라우저 코드에 직접 넣지 마세요.
- 현재 SQLite DB는 실행한 서버 한 곳에 저장됩니다.
- 다른 휴대폰/PC 간 실시간 동기화는 아직 없습니다.
- 정밀 음소 단위 발음 평가는 포함하지 않았습니다. 현재 복습 점수는 음성 전사 결과와 목표 문장의 일치도입니다.
- 실제 외부 배포 시 HTTPS가 필요합니다. 모바일 브라우저의 마이크 기능도 HTTPS 환경에서 사용하는 것이 안전합니다.
